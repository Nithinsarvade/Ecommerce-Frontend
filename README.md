# Responsive Website Project (FrontEnd) 

## Description

A responsive webpage with a fixed navbar, collapsible left menu, main content area, right-side panel, and a footer that sticks to the bottom of the page without extra white space.

## Features

- Fixed navbar
- Three sections: collapsible left menu, main content, right-side panel
- Sticky footer without white space
- Responsive layout

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript

## Setup Instructions

1. Clone or download the repository.
2. Open `web.html` in a web browser.
3. Interact with the collapsible menu and resize the window to see responsive behavior.

## Responsive Design Rules

- **992px - 1600px:** Shrinks page by 90%
- **700px - 767px:** Shrinks page by 80%
- **600px - 700px:** Shrinks width to 75%
- **≤600px:** Shrinks width to 50%

## Files Included

- `web.html` - Main webpage
- `web.css` - Stylesheet
- `web.js` - JavaScript file
